SVKO CFD NQ-ES Levels

SVKO CFD NQ-ES Levels translates the mapped underlying market's daily percentage change into practical price levels on Nasdaq 100 and S&P 500 CFD charts. It makes the mapped move visible directly on the CFD chart without manual conversion.


█ [b]OVERVIEW[/b]

The main level is 0%. It represents the chart price implied when the mapped symbol's standard daily Change % is zero. One flexible definition table controls the levels above and below that anchor, with a general default, exact chart symbol overrides, explicit values, ranges, and ATR based endpoints.

The optional current-price label remains live and shows the chart price's percentage distance from the stored 0% basis.

Hover over the current price label to see the full instrument symbol and how it was selected for the stored 0% basis. The tooltip identifies the main session mapping, outside main session mapping, SVKO CFD Symbol Mapper, or chart symbol as the source.


█ [b]HOW IT WORKS[/b]

TradingView does not expose a watchlist Change % column to Pine. The indicator reproduces that value from the mapped symbol's current and previous daily closes, removes it from the current CFD price, and stores the resulting 0% basis.

The first valid basis is held for the active calculation symbol. It changes only when that symbol changes, the indicator reloads, or its inputs change. This keeps the displayed levels fixed during each calculation period while the current price label continues to move.

ATR expressions use the last confirmed daily ATR(14) of the chart symbol, not a mapped source. The indicator converts ATR to a percentage of the cached 0% basis and rounds each ATR endpoint outwards to the selected step.


█ [b]LEVEL DEFINITIONS[/b]

The first settings group contains one [i]Level definitions[/i] text area. It requires one DEFAULT row and accepts optional exact chart symbol overrides:

    DEFAULT = -ATR/2 to ATR step 1
    TRADENATION:NFLX = 2, 1.5, 1, 0, -1, -2, -3

Each value can combine comma separated percentages and ranges. A range uses START to END and an optional step SIZE. The default step is 1, and ranges can ascend or descend. ATR expressions can use ATR, +ATR, or -ATR, optionally followed immediately by / and a positive number, then by an optional percentage-point adjustment. Examples include ATR/2, -ATR/2, ATR/3.5+1, and -ATR/2-0.5. Division is applied to ATR before the leading sign and final adjustment. Parentheses, multiplication, and other arithmetic are not supported. A comma before step is optional.

An exact chart symbol entry replaces DEFAULT for that chart. The 0% level is always added, duplicates are removed, results are sorted, and the active definition is limited to 50 unique levels. Invalid active syntax draws no partial set and displays a compact error.


█ [b]SOURCE MAPPINGS AND SESSIONS[/b]

The indicator owns separate mapping lists for the configured weekday main session and for all other times. This allows an ETF reference during the main session and a futures reference outside it.

The [i]Source mappings[/i] group contains [i]Outside main session[/i], [i]During main session[/i], and the existing [i]Main session[/i] time control. Each mapping uses one complete TradingView source and target ticker pair per line. The active session mapping always has priority.

When the active list has no match, the indicator can use SVKO CFD Symbol Mapper as a fallback on charts whose exchange prefix appears in [i]Broker prefixes[/i]. Connect [i]1st code[/i] to [i]Map: 1st code[/i] and [i]2nd code[/i] to [i]Map: 2nd code[/i] from the same Mapper instance. The decoded counterpart becomes one fallback calculation symbol for either session.


█ [b]HOW TO USE[/b]

 • Add the indicator to a supported Nasdaq 100 or S&P 500 CFD chart.
 • Define DEFAULT and any exact chart symbol overrides in [i]Level definitions[/i].
 • Confirm that the chart symbol appears on the left side of both mapping lists.
 • For symbols absent from the active list, set [i]Broker prefixes[/i], add SVKO CFD Symbol Mapper, and connect both code inputs.
 • Adjust the main session when your workflow uses different New York session hours.
 • Position and style the levels and current price label beside the latest candle.


█ [b]POSITION AND DISPLAY[/b]

Distance from candle, Other line length and Zero line length each accept comma separated interval = value pairs, such as 1m = 5, 5m = 300. Values use one minute bar equivalents: 5m = 300 means 60 bars on a five minute chart. Supported interval units are s, m, min, h, d, w and mo; mo means months. Spaces and letter case are ignored.

Listed intervals use their exact values. Between intervals, the indicator interpolates linearly by interval duration. Outside the range, it continues the straight line through the nearest two points. A single pair gives a constant value. Months use Pine's standard average duration. Invalid pairs, negative entered values and duplicate intervals display a position settings error and draw no levels.

Distance from candle is the horizontal gap from the latest candle to the start of the longest level line. Shorter lines start further right because all right endpoints stay aligned. Other line length controls the upper and lower lines; Zero line length controls the 0% line.

Resolved values are converted to chart bars and rounded. Below one minute, the conversion divisor remains one minute. Negative extrapolated gaps become zero and lines retain at least one chart bar. The gap is capped at 495 chart bars. Lines are shortened when needed to keep the gap plus the longest line within TradingView's limit of 500 future bars.

Pine does not provide reliable pixel positioning for these drawings. Interval settings let you adjust their layout, but cannot guarantee identical visual spacing at different zoom levels.

The zero, upper, and lower levels have independent styles. The current-price label can sit immediately after the latest candle, use additional padding, or align with the level endpoints.


█ [b]ALERTS[/b]

This indicator does not define alert conditions.


█ [b]LIMITATIONS[/b]

The reproduced percentage uses the mapped symbol's standard TradingView daily data and is not a direct watchlist read. Futures daily closes can inherit settlement behaviour from TradingView's ticker settings.

The 0% basis is a live snapshot. Reloading at another time can produce a different basis, and historical bars cannot reproduce the exact time of an earlier live snapshot. No future data is used.

Feed timing, spreads, currencies, sessions, instrument specifications, and data permissions can make the CFD and calculation symbol diverge. If neither the active mapping nor the configured Mapper fallback supplies a valid symbol, or if daily data is unavailable, the indicator draws nothing.

ATR ranges use the last confirmed daily ATR rather than the developing current daily ATR. They stay stable during the day but do not include volatility added by the unfinished daily bar. ATR divisors must be positive. The active definition is limited to 50 unique levels.
